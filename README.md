# test-vocacional-upds.
Aplicación web del Test de Orientación Vocacional CHASIDE adaptado para la Universidad Privada Domingo Savio (UPDS) sede Sucre. Diseñada para ferias vocacionales, permite a los estudiantes evaluar sus intereses y aptitudes en minutos desde su celular, generando gráficos interactivos y sugiriendo carreras afines a su perfil.
